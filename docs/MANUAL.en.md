# MarkdownLab — User guide

## Installation

Install the Windows x64 installer or extract the portable ZIP from GitHub Releases. WebView2 Runtime is required; .NET is included. Optionally register MarkdownLab in Windows Open with, then choose it as the default app for Markdown files.

## Reading and editing

Open Markdown files with Ctrl+O, drag and drop or Windows Open with. Use Read, Edit or Split view and the outline to navigate. Click + to create a tab and × to close it. An asterisk indicates unsaved changes. Opening a file from Explorer forwards it to the existing window.

## Editing tools

Ctrl+S saves, Ctrl+Shift+S saves as, Ctrl+W closes the tab, Ctrl+F finds and Ctrl+H replaces. Ctrl+B and Ctrl+I apply bold and italics. Alt+Up/Down moves lines. The formatting toolbar supports headings, bold, italic, lists, code, links, images and tables. Export HTML or PDF from File; verify the resulting output.

## Settings and recovery

Tools > Settings > General controls the interface language, startup update checks and tab restoration. Appearance controls theme. Editor controls word wrap and spelling language independently. Saving controls recovery intervals and optional autosave. Autosave only affects named files and is disabled by default. Windows dictionary availability varies. Right-click a spelling error for suggestions. Recovery data lives in %LOCALAPPDATA%\MarkdownLab\Workspace. Back up important files separately.

## Updates

Help > Check for updates checks GitHub stable releases; installed copies download a SHA-256 verified installer after confirmation and require saving unsaved documents. Portable copies open the download page.
