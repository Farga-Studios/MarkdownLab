# MarkdownLab v1.6.1 — Stable

Primera versión estable pública de MarkdownLab, lector y editor Markdown de Sealsworn para Windows.

## Funcionalidades
- Lectura, edición y vista dividida; índice de encabezados, búsqueda y reemplazo.
- Pestañas, archivos recientes, recuperación de cambios y autoguardado opcional.
- Herramientas de formato, corrector ortográfico basado en Windows y exportación HTML/PDF.
- Interfaz personalizada, temas claro y oscuro, modo concentración e icono multirresolución.
- Instalador con asociación opcional de archivos Markdown y apertura en una sola instancia.
- Comprobación de actualizaciones mediante GitHub Releases con verificación SHA-256.

## Descargas
- **MarkdownLab-Setup-win-x64.exe**: instalador.
- **MarkdownLab-portable-win-x64.zip**: versión portátil.

Windows x64; requiere WebView2 Runtime. .NET 8 incluido. Licencia MIT. Manual en español incluido en ambos paquetes.

La actualización de extremo a extremo desde esta versión se verificará cuando exista una versión posterior.
